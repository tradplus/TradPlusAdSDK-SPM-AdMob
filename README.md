# TradPlus AdMob Adapter Swift Package

Swift Package Manager support for the TradPlus AdMob adapter (15.12.0).

## Installation

```text
https://github.com/tradplus/TradPlusAdSDK-SPM-AdMob.git
```

```swift
.package(url: "https://github.com/tradplus/TradPlusAdSDK-SPM-AdMob.git", exact: "15.12.0")
```

Requires iOS 13.0 or later.

Third-party dependency: Google Mobile Ads SDK `13.6.0`.

## Notes

- This package automatically resolves `TradPlusAdSDK` 15.12.0.
- Add `-ObjC` to the app target's `Other Linker Flags` if required.
